# Changelog

## 1.0.0 — 2026-10-30

- Published the first formal open-source SDP specification release under Apache-2.0.
- Released the general core, AI authority model and exchange/rights semantics.
- Included knowledge-service, intent-matching, agent collaboration, NFT succession and agent-created token cases.
- Versioned the illustrative mandate envelope as `sdp/1.0` and retained the same authority semantics.
- Added LICENSE, NOTICE, VERSION, release notes and a compatibility policy.
- Bundled local structural and authorization-boundary validation.

## 0.2.0-draft.1 — 2026-10-30

- Added an agent-created token case covering context-derived token design, authorized creation, distribution, control assignments and transfer of creation entitlements.
- Reframed the protocol around personal context, user-authorized agents, scoped exchange and attributable outcomes.
- Replaced seats, NFTs and mint lifecycles as core objects with principal, context, mandate, representation, agreement, receipt, allocation and feedback.
- Preserved the initial three documents under `cases/agent-created-nft/`, with application-profile scope notices and corrected internal references.
- Generalized developer authority limits, delegation, assignment and finite execution rights.
- Added knowledge-service, intent-matching and agent-collaboration examples, architecture, security boundaries and structural validation.

## 0.1.0-draft.1 — initial local draft

An application-focused specification for agent-created artifacts and persistent-seat succession. It is retained as a case rather than maintained as the general protocol.
