# Silicon Dreamers Protocol 1.0.0

Released: 2026-10-30 · License: Apache-2.0 · Tag: `v1.0.0`

**The first formal open-source release of the SDP specification.**

SDP describes how personal context becomes an externally useful representation, capability or action through a user-authorized AI agent, and how exchange outcomes return to the agreed beneficiaries.

## Included

- The application-neutral core: principals, context, mandates, representations, agreements, receipts, value allocation and feedback.
- AI delegation and bounded autonomy, with explicit limits on developer and operator authority.
- Separate rights for disclosure, invocation, delegation, assignment, settlement and memory.
- Application cases for knowledge services, intent matching, agent collaboration, NFT creation/succession and agent-created tokens.
- An illustrative `sdp/1.0` mandate schema, synthetic examples and a standard-library Python validation tool.
- Architecture, security boundaries, contribution guidance, versioning policy and Apache-2.0 licensing.

## Validate

Requires Python 3.10 or later; no third-party packages are required.

```sh
python tools/validate.py
```

Validation covers example structures and references, local documentation links, authorization-boundary rejection cases, delegation attenuation and shared parent quota consumption. It does not authenticate the synthetic proof references or execute an exchange.

## Release scope

This is a specification and reference-material release. It does not ship a production agent runtime, universal signing format, audited smart contracts or a deployed settlement network. Implementations must provide concrete wire profiles, enforcement and their own conformance evidence.

NFT issuance and agent-created tokens are applications of SDP. Neither is required by the general protocol.
