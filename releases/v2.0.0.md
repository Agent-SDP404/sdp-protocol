# agent-sdp v2.0.0

Specification release · Reference implementation: alpha · Apache-2.0

**Data becomes capability. Agents carry it into exchange.**

This release establishes agent-sdp as an independent protocol for data-mediated capabilities and exchange. The source model now covers people, organizations, public data, research, devices, environments and Agent-generated information.

## New in this release

- Independent agent-sdp identity, a redesigned repository introduction and a clear data-to-exchange path.
- Data sources and their controllers separated from the principal authorizing a task.
- A concrete local wire profile with signed source descriptors, mandates, accepted agreements, assignments, results, receipts and acknowledgements.
- An executable Python reference alpha with real Ed25519 verification and SQLite-backed rights consumption, replay protection, assignment and revocation.
- Runnable research exchange, token-creation simulation and NFT genesis/succession simulation, with public proof records and an offline verifier.
- A documented relationship to MCP/A2A, an enforcement matrix and a focused engineering roadmap.

## Run

```sh
python -m pip install -r requirements.txt
python -m agent_sdp.demo --output dist/demo-trace.json
python -m agent_sdp.verify_trace dist/demo-trace.json
python tools/check.py
```

## Compatibility and scope

The general source/principal model and concrete signed envelope are a major-version change. V1 fixtures are retained as historical examples; do not relabel old signed messages as v2 authorization. The v1.0.0 tag and release remain unchanged. The existing GitHub repository URL is retained to preserve links.

NFTs and tokens remain applications of the protocol. The reference executes deterministic local adapters; it does not call a live model, mint an on-chain asset, send funds, or ship an MCP/A2A network integration. The specification release is formal; the new reference implementation is alpha and has not been independently audited.

The release package is the source ZIP attached to the original release, with its checksum in `SHA256SUMS.txt`. The archive includes the specification, source, test suite and synthetic proof bundle, excluding environments, credentials and local build output.
