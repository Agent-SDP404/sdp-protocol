# agent-sdp v3.0.0

Protocol identity is now uniformly **agent-sdp**, including current documentation and changelog wording.

The Python module is `agent_sdp`; distribution is `agent-sdp-reference`. Specification identifiers use `SDP-0001` through `SDP-0004`.

The signed wire namespace is `agent-sdp/3.0`. Existing signatures from earlier versions cannot be relabeled or reused. Obtain fresh acceptance and use a fresh local ledger for this profile. Public synthetic traces have been regenerated and verified. Historical Git tags and already-published archives remain unchanged.

Run `python -m pip install -r requirements.txt`, then `python -m agent_sdp.demo --output dist/demo-trace.json` and `python tools/check.py`.

Reference maturity remains alpha; asset adapters are local simulations. Apache-2.0.
